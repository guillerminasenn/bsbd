
# BSBD

This repo contains code + notebooks for Bayesian seismic blind deconvolution experiments.

## Recreate the environment

Requires Python 3.10 (see `pyproject.toml`). From the repo root:

```bash
python -m venv your-env
source your-env/bin/activate

python -m pip install -U pip
python -m pip install -r requirements.txt
```

Then open any notebook in `notebooks/` and run cells top-to-bottom.
